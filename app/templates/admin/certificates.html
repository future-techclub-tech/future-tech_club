Generate and send a demo certificate

Create one real certificate for a selected student. It is dispatched to their dashboard immediately, listed below under Generated certificates, and can be deleted there. Email is also sent when configured.

Excel / CSV mail merge

Use a row per recipient. Map each spreadsheet column to the certificate fields. Generated certificates stay private until an admin approves and dispatches them to all users, a domain, or one selected account.

Import finished student certificate PDFs

Upload multiple PDFs directly or one ZIP. Name every PDF exactly with the student’s Student ID/PRN, for example STUDENT123.pdf. Choose whether to use all matching IDs or select recipients from the active student list, like Mailings. The system assigns each matching file to that account, adds a unique verification QR and certificate number to the lower-left of page one, and keeps certificates pending until dispatch.
